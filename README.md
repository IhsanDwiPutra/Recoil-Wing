# Recoil Wing 🦅💥

Sebuah game arcade berbasis Pygame dengan twist unik: **menembak ke bawah untuk melayang menggunakan recoil physics!**

## Fitur Utama
- **Recoil Flap Physics:** Mengendalikan terbang bukan dengan sayap biasa, tapi dorongan tolak peluru.
- **Destructible Obstacles:** Balok rintangan dapat ditembak untuk membuka jalan pintas.
- **Game Juice:** Screen shake, partikel asap, kilatan tembakan, dan arcade visual yang responsif.

## Prasyarat
- Python 3.10+
- Pygame (`pip install pygame`)

## Menjalankan Game
```bash
python main.py
```
